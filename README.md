# Pokémon TCG Database

Projeto desenvolvido durante meus estudos de Banco de Dados Relacional no Bootcamp de Análise de Dados com Python.

## Sobre o Projeto

Este projeto consiste na modelagem e implementação de um banco de dados relacional para armazenar informações de cartas do Pokémon Trading Card Game (TCG).

A proposta foi utilizar um tema de interesse pessoal para praticar conceitos fundamentais de bancos de dados, desde a modelagem das entidades até a criação de consultas SQL para recuperação e análise das informações armazenadas.

## Objetivos de Aprendizagem

* Compreender a estrutura de bancos de dados relacionais;
* Aplicar conceitos de modelagem utilizando MER e DER;
* Criar relacionamentos entre tabelas por meio de chaves primárias e estrangeiras;
* Praticar operações CRUD;
* Desenvolver consultas utilizando filtros, ordenação, agrupamentos e junções;
* Explorar recursos como views e índices.

## Tecnologias Utilizadas

## Conceitos Praticados
